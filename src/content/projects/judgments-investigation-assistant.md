## Background

During credit investigation and compliance review, banks need to check whether a client or related party is involved in litigation, which traditionally means searching and reading judgments by hand. This project explores using a large language model to collect and summarize the relevant judgments.

## Technical highlights

- LLM calls through AWS Bedrock, with results stored in a database.
- An interactive demo UI built with Streamlit.
- Containerized deployment with Docker.
